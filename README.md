# daily-market-brief

Automated daily "Daybreak-style" markets brief, generated by a Claude Code Trigger.

## How it works

- `source-notes.md` is a running memory file: which sources are fast/reliable for which
  data type, query phrasings that work, dead ends to avoid. Every run reads it before
  searching and appends a short update after.
- `prompt.md` is the exact prompt pasted into the Trigger config. It tells Claude to:
  1. Read `source-notes.md` first.
  2. Research and write the brief using live web search (deep-research skill), biased
     toward the sources/queries `source-notes.md` says work well.
  3. Deliver the brief.
  4. Append a short "lessons learned" entry to `source-notes.md` and commit it.
- Each day's brief is saved under `briefs/YYYY-MM-DD.md`.

Because the memory lives in this repo (not in any one chat session), quality should
compound run over run even though every Trigger fire starts from a fresh container.
